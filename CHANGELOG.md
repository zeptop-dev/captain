# Changelog

One entry per release tag, newest first, condensed from the commit subjects
between that tag and the previous one (`git log --format=%s <prev>..<tag>`).
Merge commits and formatting-only commits are left out. Binaries and
`SHA256SUMS` for every tag are on the GitHub Release; the in-app updater
installs them (Settings → Version and updates).

- **v0.57.2** (2026-09-17) — dynamic speed limit: a report with no traffic at all (a quiet node after the burst) now also runs the evaluation, so a burst that ended is throttled on the next report instead of never
- **v0.57.1** (2026-09-17) — dynamic speed limit: a user whose burst ended before the next report is still evaluated (the limiter looked only at users present in the current report, so a download that stopped a minute earlier never triggered)
- **v0.57.0** (2026-09-17) — audit rules (Settings → Audit rules): panel-wide block/log rules pushed to every node, hits stored 90 days and shown per rule and per user, optional Telegram notice, auto-ban after N hits in M hours (`GET/PUT /api/admin/audit-rules`, `GET /api/admin/audit-log`, `GET/PUT /api/admin/settings/audit`, webhooks `user.audit_hit`, `user.audit_banned`); dynamic speed limit (Settings → Dynamic speed limit): sustained high average rate across nodes puts a temporary limit on the user, with hours and whitelist, shown and liftable in the user drawer (`GET/PUT /api/admin/settings/dynlimit`, `DELETE /api/admin/users/{id}/dyn-limit`, webhook `user.throttled`); node option "Egress follows ingress" (`egress_by_ingress`): inbounds bound to an address exit from it; bosun v0.44.0
- **v0.56.1** (2026-09-16) — Snell: sing-box subscriptions carry snell lines (shared psk, `user_key` on multi-user inbounds); multi-user lines are left out of Surge/Stash/mihomo documents, whose clients have no user key (v0.55.0 handed them the key as psk, which failed); form hint says so; bosun v0.42.1
- **v0.56.0** (2026-09-16) — connection log, off by default (Settings → Connection log): nodes report every accepted connection (user, inbound, client IP, destination host and port, TCP/UDP) from the sing-box, xray and hysteria logs, stored in `conn_log` for the configured days (7), listed per user in the user drawer, deleted when switched off; `GET/PUT /api/admin/settings/connlog`, `GET /api/admin/users/{id}/connections`; bosun v0.42.0
- **v0.55.0** (2026-09-16) — Snell inbounds gain "Multi-user (sing-box)": each user gets their own key and per-user accounting, the subscription hands it out as the psk (bosun v0.41.0, which serves snell from sing-box and keeps snell-server for obfs tls); bosun v0.40.0 core isolation (`cores.user`) shows up in the node doctor
- **v0.54.0** (2026-09-16) — origin check on cookie-authenticated writes (admin, portal, login/register/reset): a cross-site Origin/Referer gets 403, API tokens and reads are exempt; saving or enabling an inbound whose transport+port collides with another enabled inbound or a forward on the node is refused with 409; node alerts raised within 30 s are batched into one Telegram message (webhooks unchanged); self-update and the backup job check free space first; bosun v0.39.1 (mita 3.37.0 binds line addresses natively, sing-box 1.14.1-r1)
- **v0.53.0** (2026-09-16) — traffic thresholds: Settings → Mail takes a list of used-percentages (default 90) and users are told once per threshold per quota period, highest first; webhooks gain `subscription.traffic`, `user.first_connected` (first traffic ever seen for a user, timestamp shown in the user drawer) and `user.not_connected` (a usable plan for a day without any traffic, once)
